01 — About

A software developer who ships the whole feature

I'm a software developer with production experience across the full path data takes through a product — from the Python pipelines that collect and extract it, through the NestJS APIs and PostgreSQL schemas that store and serve it, to the Next.js dashboards that turn it into something a business can act on.

At Metawatt I own features end to end across four production repositories, on a code-reviewed, CI-gated team workflow. In practice that means I'm as comfortable writing a database migration and a row-level security policy as I am wiring the chart that finally displays the result — and I don't hand off the middle.

I gravitate toward problems where the data is messy and the answer matters: inconsistent sources, PDF-only records, bot protection, and pipelines that have to keep running whether or not the world cooperates.

  • End to end, not edge to edge

    Schema, endpoint, client, and UI are one feature. I build them as one, so nothing gets lost between layers.

  • Correctness over cleverness

    Bounded queries, guarded intake, indexed read paths, retry tallies — the unglamorous work that keeps production data trustworthy.

  • Built for a team to read

    Git-flow pull requests, review feedback taken seriously, and CI lint gates held green across every repository I touch.
