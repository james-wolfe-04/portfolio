01 — About

A quick introduction

I'm a full-stack developer with production experience across the whole data stack — from the Python pipelines that collect and extract data, through the NestJS APIs and PostgreSQL schemas that store and serve it, to the Next.js dashboards that make it readable.

Day to day I ship features end to end across four production repositories on a code-reviewed, CI-gated team workflow — which means I'm as comfortable writing a database migration as I am wiring up the UI that finally displays the result.
